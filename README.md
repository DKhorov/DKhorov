## [ RU ] ПРОФИЛЬ

Деятельность в индустрии информационных технологий ведется с конца 2019 года, начиная с автоматизации систем на базе Python и создания специализированных микросервисов. В настоящее время компетенции охватывают проектирование распределенных высоконагруженных веб-платформ, интеграцию решений искусственного интеллекта и глубокую низкоуровневую разработку программно-аппаратных комплексов.

Каждая инициатива — от независимых инженерных исследований до масштабных платформ — реализуется в соответствии с жесткими коммерческими стандартами. Это включает проектирование масштабируемой архитектуры, ведение сквозной технической документации, управление интеллектуальной собственностью и соблюдение регламентов корпоративного брендинга.

### КЛЮЧЕВЫЕ АРХИТЕКТУРНЫЕ ДОСТИЖЕНИЯ

#### Флагманский проект: Экосистема социальной сети AtomGlide.com
* **Масштабируемость и метрики:** Разработана и развернута отказоустойчивая социальная платформа с развитой инфраструктурой. Проект демонстрирует высокие показатели вовлеченности: успешно зарегистрирована обширная база активных пользователей, а внутренний объем данных превышает 3000 верифицированных и структурированных публикаций (постов).
* **Архитектурный стек:** Программная логика серверной части построена на базе Node.js (Express.js) с развертыванием на выделенных VPS-серверах. Клиентский интерфейс функционирует на базе React 18 с оптимизацией доставки контента через инфраструктуру Vercel. 
* **Инфраструктура хранения данных:** Распределенная СУБД MongoDB. Отказоустойчивая маршрутизация трафика и доставка контента обеспечиваются за счет интеграции с CDN-сетями провайдера Hoster.by.
* **Управление доменной структурой:** Администрирование распределенной сети адресов `atomglide.com`, `atomglidedev.ru` и `geromik.ru`.
* **Профессиональное признание:** Технические решения платформы были высоко оценены экспертными комиссиями и удостоены почетных мест на профильных олимпиадах и научно-технических конкурсах республиканского уровня.

#### Системное программирование: Разработка Bare Metal ядра для архитектуры ThinkPad x201
* **Низкоуровневый инжиниринг:** Разработано с нуля монолитное программное ядро, функционирующее непосредственно на аппаратном уровне без использования сторонних операционных систем или готовых абстракций (Bare Metal).
* **Драйверы и интерфейсы:** В рамках ядра реализован аппаратный драйвер ввода для обработки прерываний PS/2-клавиатуры.
* **Графическая подсистема:** Спроектирован и внедрен графический модуль стандарта VESA. Интегрирован механизм двойной буферизации (Double Buffering), что позволило полностью устранить артефакты визуализации (тиринга) и обеспечить высокую производительность вывода графической информации напрямую через видеопамять.

#### Systems Engineering: Custom Bare Metal Kernel for ThinkPad x201
* **Low-Level Kernel Engineering:** Programmed a monolithic operating system kernel from scratch, running directly on the hardware layer without external operating system abstractions or pre-built environments (Bare Metal).
* **Drivers & Interface Subsystems:** Implemented a low-latency hardware input driver for handling PS/2 keyboard interrupts.
* **Graphics Architecture:** Designed and deployed a VESA-compliant graphics subsystem. Integrated a hardware double-buffering mechanism to eliminate visualization artifacts (tearing), ensuring high-performance graphic rendering directly via video memory.
